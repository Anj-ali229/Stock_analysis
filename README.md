Overview-

This project focuses on the analysis of historical stock market data using Python.
It demonstrates end-to-end data ingestion, preprocessing, analysis, and visualization of time-series financial data to extract meaningful trends and insights.
While the domain is finance, the techniques used—data cleaning, statistical analysis, and visualization—are highly transferable to health informatics and clinical data analytics.

Objectives-

Analyze historical stock price data
Identify trends and patterns using statistical indicators
Visualize stock performance over time
Build a reusable data analysis workflow using Python

Tech Stack & Libraries-

Programming Language: Python

Libraries Used:

Pandas – data manipulation and preprocessing
NumPy – numerical computations
Matplotlib – data visualization
